# DigiTokenBar

**AI 코딩 토큰으로 디지몬을 키우는 macOS 메뉴바 앱**

[English](README.md) · **한국어** · [日本語](README.ja.md)

</div>

> **상태:** [PokeTokenBar](https://github.com/chattymin/PokeTokenBar)에서 갈라져 나온 개인 프로젝트이고, 개발 중이에요.
> [최신 배포판](https://github.com/deadlylaid/DigiTokenBar/releases/latest)을 받아 쓰거나, 직접 빌드할 수 있어요.

DigiTokenBar는 이미 쓰고 있는 AI 코딩 도구(Claude Code, Codex, Gemini CLI 등)의 토큰 사용량을 내 Mac의
기록 파일에서 읽어, 디지몬의 경험치로 바꿔 줘요. 바탕에는 PokeTokenBar의 사용량 추적 기능이 그대로 있어요.
오늘 쓴 토큰, 비용, 5시간·주간 공식 사용 한도를 볼 수 있어요.

## 설치

macOS 14 이상이 필요해요. Apple 실리콘과 인텔 Mac 모두 돼요.

**Homebrew로 설치하기** (추천):

```sh
brew install --cask deadlylaid/tap/digitokenbar && open -a DigiTokenBar
```

설치하고 바로 켜요. 처음에는 알을 고르는 창이 뜨고, 그 뒤로는 Dock 아이콘 없이 화면 오른쪽 위 메뉴 막대에 살아요.
메뉴 막대가 꽉 차면 macOS가 아이콘을 노치 뒤에 숨겨요. 그럴 땐 앱을 다시 열면(Spotlight, 응용 프로그램 폴더,
`open -a DigiTokenBar`) 창이 다시 떠요.
Homebrew가 "인터넷에서 받은 파일" 표시를 지워 줘서, 아래 3번의 경고 없이 바로 열려요. 그다음 4번만 보면 돼요.

**또는 직접 내려받기:**

1. [최신 배포판](https://github.com/deadlylaid/DigiTokenBar/releases/latest)에서 **DigiTokenBar.zip**을 받아
   압축을 풀어요.
2. **DigiTokenBar.app**을 응용 프로그램 폴더로 옮기고 열어요.
3. 처음 열 때 macOS가 "개발자를 확인할 수 없다"며 열지 않아요. DigiTokenBar는 무료 팬 프로젝트라 Apple의
   확인(공증)을 받지 않았기 때문이에요. **시스템 설정 → 개인정보 보호 및 보안**을 열고 아래쪽에서
   DigiTokenBar 옆의 **그래도 열기**를 눌러 주세요. 터미널에서 아래 명령을 실행해도 돼요.

   ```sh
   xattr -dr com.apple.quarantine /Applications/DigiTokenBar.app
   ```

4. Claude Code의 공식 사용 한도를 보여 주려고 앱이 키체인에서 Claude Code 로그인 정보를 읽어요. 그래서 macOS가
   한 번 물어봐요. **항상 허용**을 눌러 주세요. 배포판은 늘 같은 서명을 써서, 업데이트한 뒤에도 그대로 돼요.

**업데이트:** 새 버전이 나오면 앱이 알려 줘요. 업데이트를 누르면 Homebrew로 깐 앱은 알아서 올라가요
(`brew upgrade --cask deadlylaid/tap/digitokenbar`와 같아요). 직접 내려받아 깐 앱은 배포 페이지가 열리니, 새
`DigiTokenBar.zip`의 앱으로 바꾸면 돼요. 디지몬, 저장, 설정은 그대로 남아요.

## 어떻게 키우나요

1. **알 고르기.** 아직 안 키운 줄기 중에서 알 3개가 무작위로 나와요. 졸업시켜 본 줄기는 언제든 다시 고를 수
   있어요. 하루 안에 안 고르면 자동으로 정해져요.
2. **평소처럼 코딩하기.** 토큰 200,000개가 경험치 1이에요. 하루 최대 150까지 쌓여요. 알에서 졸업까지
   적어도 일주일쯤 걸려요.
3. **진화.** 줄기 하나가 바이탈 브레이슬릿 카드 한 장이에요. 줄기 40개, 디지몬 636종(아머체 22종 포함)이
   있고 유년기 I부터 궁극체까지 자라요. 진화는 그 카드의 경로를 따르고, 카드의 조건이 길을 열어요. 바이탈 값은 하루 평균
   코딩 시간으로, 트로피는 좋은 날(코딩한 날, 한도를 안 넘긴 날, 도구를 2개 쓴 날)로, 배틀 수와 승률은
   배틀로 세요. 열린 길 중에서
   어느 길로 갈지는 확률로 뽑는데, 코딩하는 방식이 그 확률을 기울여요. 낮에 꾸준히 쓰면 백신, 여러 도구를
   여러 날 쓰면 데이터, 새벽이 늘거나 한도를 채우면 바이러스 쪽이에요. 지금과 같은 속성으로 가는 길은 조금 더
   잘 나와요. 단계마다 한 번만 뽑고, 앱을 다시 켜도 다시 뽑지 않아요. 아무 조건도 못 채우면 쉬운 길로 가요.
   숨겨진 진화도 몇 개 있어요(버그 20마리 잡기, 사용 한도 3번 채우기). 숨겨진 진화를 얻으면 뽑기 없이 그쪽으로
   가요.
4. **아머 진화.** 몇몇 성장기 디지몬은 평소처럼 자라는 대신 디지멘탈을 써서 아머체가 될 수 있어요. 조각을
   모아요(가끔 나오는 황금 버그, 손님의 선물, 출석 도장 판, 놀람 점수). 같은 종류 3개가 모이면 디지멘탈이
   돼요. 기적과 운명의 황금 디지멘탈은 드물게 통째로 오고, 단계를 건너뛰어요(브이몬 → 매그너몬).
5. **친구와 합체.** 카드에 합체(조그레스) 진화가 있는 단계를 다 채우면, 디지몬이 최대 24시간 동안 친구의
   코드(배틀 코드와 같아요)를 기다려요. 친구의 디지몬이 카드에 적힌 짝("바이러스 완전체", "엔젤몬" 등)에
   맞으면 합체 진화하고, 장면에 친구의 디지몬이 걸어 들어와요. 코드가 없거나 "합체 없이 진화"를 누르면
   평소처럼 진화해요. 기다리는 동안 쌓인 경험치는 다음 단계로 넘어가요. 정해진 궁극체끼리의 합체(워그레이몬
   + 메탈가루몬 = 오메가몬 외 10쌍)는 짝을 키워 본 적도 있어야 해요.
6. **졸업.** 궁극체를 다 채우면 도감에 남기고 졸업해요. 그리고 새 알이 와요.

## 기능

- **장면:** 디지몬이 걷고, 자고, 필살기로 버그를 잡아요. 큰 버그는 세 번 맞혀야 잡혀요. 사용 한도가 꽉 차
  있으면 아파하고, 새벽에는 졸려해요.
- **도감:** 줄기마다 단계별로 보여요. 키워 본 디지몬만 그림이 나오고 나머지는 그림자예요. 숨겨진 진화,
  디지멘탈로 가는 아머체, 합체로만 만나는 디지몬은 힌트(필요한 디지멘탈이나 짝)가 나와요. 모든 줄기에서
  이름으로 찾고, 거르고, 정렬할 수 있어요.
- **바탕화면 펫과 메뉴바:** 바탕화면(설정 → 바탕화면 펫)과 메뉴바에 디지몬이 나와요. 성장률도 볼 수 있어요.
  마우스로 문지르면 하트가 나오고, 두 번 누르면 점프해요. 크기는 작게·보통·크게 중에서 고를 수 있어요.
  설정 → 디지몬 → 제자리에 있기를 켜면 걸어 다니지 않고 가운데에 있어요.
- **에이전트 반응:** Claude Code가 일하면 바탕화면 펫 머리 위에 점이 깜빡이고, 확인이 필요하면 말풍선을
  띄우고, 끝나면 기뻐해요. `sh tools/digimon/install-agent-hooks.sh`를 한 번 실행하면 설정돼요
  (`~/.claude/settings.json`을 먼저 백업하고, 원래 있던 훅은 그대로 둬요). 다른 에이전트는
  `digitokenbar://agent?state=<working|waiting|done|idle>&label=<이름>` 링크를 열면 돼요.
- **배틀:** 배틀 코드로 다른 DigiTokenBar 사용자와 싸워요. 내 코드를 복사해 메신저로 보내고, 상대 코드를
  붙여넣으면 두 앱에서 같은 배틀이 펼쳐져요. 서버가 필요 없어요. 하루 5번의 연습 배틀(야생 디지몬)도 세요.
  배틀은 경험치를 주지 않고, 카드의 배틀 수·승률 조건을 채워요. 친구와 합체할 때도 같은 코드를 써요.
  코드에는 무작위 이용자 번호와 디지몬 정보만 들어가요.
- **오늘:** 매일 오늘의 기운(맑음, 버그 소동, 투지, 손님 많은 날, 유성우)이 정해지고, 손님 디지몬이 놀러 와요.
  손님은 대부분 내 도감의 디지몬이고, 1% 확률로 처음 보는 디지몬이 와요(도감에 "목격"으로 남아요). 손님에 따라
  놀람 점수가 쌓여요. 코딩한 날마다 출석 도장이 하나씩 찍히고, 7개를 모으면 처음 보는 아주 드문 손님이 바로 와요.
  운은 사용량과 상관없고 다시 뽑을 수도 없어요.
- **저장:** 자동 백업(앱을 켤 때와 12시간마다, 최근 10개 보관)이 있어요. 내보내기·가져오기로 다른 Mac에
  옮길 수 있어요.
- **빠른 성장(테스트):** 단계마다 필요한 경험치를 10분의 1로 줄여서 빨리 둘러볼 수 있어요.

디지몬 화면은 한국어와 영어를 지원해요.

## 지원하는 도구

Claude Code, Codex, Gemini CLI, Antigravity, OpenCode, Hermes Agent, Cursor, Grok Build CLI,
Copilot CLI, Kiro CLI, Pi Agent, omp, omo, Aside, Kimi Code, Devin CLI. 공식 사용 한도는 Claude Code,
Codex, Antigravity, OpenCode Go, Grok에서 보여요. 이 부분은 PokeTokenBar와 같아요. 도구마다 어디서
사용량을 읽는지는 원본의 [데이터 출처](https://github.com/chattymin/PokeTokenBar/blob/main/README.ko.md)를
봐 주세요.

## 직접 빌드하기

macOS 14 이상, Swift 6이 들어 있는 Xcode가 필요해요.

```sh
bash scripts/create-signing-cert.sh            # 한 번만: 내 Mac 전용 서명 인증서. 다시 빌드해도 키체인 "항상 허용"이 유지돼요
PTB_NATIVE_ARCH_ONLY=1 bash scripts/build-app.sh  # 빌드하고 /Applications/DigiTokenBar.app 에 설치
swift test --parallel                          # 테스트
```

## 디지몬 데이터 출처

- **디지몬과 진화:** [Wikimon](https://wikimon.net)(글은 CC BY-SA 3.0). `tools/digimon/build_data.py`와
  `gen_catalog.py`로 만들어요.
- **카드별 진화 경로**(카드에 어떤 진화가 있고 어느 것이 합체인지): 기기를 정리한 팬 자료, 주로 humulos.com.
  조사 기록은 `tools/digimon/research`에 있어요.
- **필살기와 한국어 이름:** 공식 한국어 디지몬 도감(digimon.net/reference_ko).
- **그림은 이 저장소에도 앱에도 들어 있지 않아요.** 앱이 실행 중에 wikimon.net에서 받아
  `~/Library/Application Support/DigiTokenBar/digimon-sprites`에 저장해요.

## 개인정보

- 토큰 사용량은 내 Mac에서만 읽고, 어디에도 올리지 않아요.
- 외부 접속: 그림을 받는 wikimon.net, PokeTokenBar에 원래 있던 공식 한도·장애 공지 확인, 그리고 업데이트
  확인용으로 이 저장소의 GitHub 최신 배포판 정보예요. PokéAPI에서는 아무것도 받지 않아요.
- Claude Code 훅은 설치 스크립트를 직접 실행할 때만 설치돼요.
- 디지몬 저장 파일과 백업은 `~/Library/Application Support/DigiTokenBar/`에 있어요.

## 만든 사람과 라이선스

- chattymin의 [PokeTokenBar](https://github.com/chattymin/PokeTokenBar)에서 갈라져 나왔어요. 사용량 추적,
  지원 도구, 사용 한도를 비롯한 앱의 대부분은 원본 작업이에요. 원본의 포켓몬 기능은 지웠어요.
- **MIT** 라이선스예요. [LICENSE](LICENSE)를 봐 주세요. 원본의 저작권 표시를 그대로 두었어요. 이 라이선스는
  이 프로젝트의 소스 코드에만 해당하고, 다른 회사의 상표·그림·데이터에 대한 권리는 주지 않아요.
- DigiTokenBar는 **비공식, 비상업 팬 프로젝트**예요. 반다이, 토에이 애니메이션, 반다이남코와 관계가 없고,
  그들의 승인이나 후원을 받지 않았어요. "디지몬"과 관련된 이름, 캐릭터, 그림은 각 권리자의 것이에요. 앱에는
  디지몬 그림이 들어 있지 않아요.
- `tools/digimon/research`에는 데이터를 확인하려고 다른 사이트의 짧은 인용을 출처와 함께 넣어 두었어요.
