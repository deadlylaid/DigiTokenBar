# DigiTokenBar

**AI コーディングのトークンでデジモンを育てる macOS メニューバーアプリ**

[English](README.md) · [한국어](README.ko.md) · **日本語**

</div>

> **状態:** [PokeTokenBar](https://github.com/chattymin/PokeTokenBar) から派生した個人プロジェクトで、開発中です。
> [最新リリース](https://github.com/deadlylaid/DigiTokenBar/releases/latest)をダウンロードするか、ソースからビルドできます。

DigiTokenBar は、普段使っている AI コーディングツール(Claude Code、Codex、Gemini CLI など)のトークン使用量を
Mac のローカルログから読み取り、デジモンの経験値に変えます。土台は PokeTokenBar の使用量トラッカーで、
今日のトークン、コスト、公式の 5 時間・週間の使用上限を確認できます。

## インストール

macOS 14 以降が必要です。Apple シリコンと Intel のどちらの Mac でも動きます。

**Homebrew でインストール**(おすすめ):

```sh
brew install --cask deadlylaid/tap/digitokenbar; open -a DigiTokenBar
```

インストールしてそのまま起動します(brew がほかのことで警告を出してもアプリは起動します)。初回は卵を選ぶウィンドウが開き、その後は Dock アイコンなしで画面右上のメニューバーに
常駐します。メニューバーがいっぱいだと macOS がアイコンをノッチの裏に隠します。そのときはアプリをもう一度開くと
(Spotlight、アプリケーションフォルダ、`open -a DigiTokenBar`)ウィンドウが戻ります。
Homebrew がダウンロードの検疫属性を外すので、下の 3 の警告なしで開けます。そのあとは 4 だけ確認してください。

**または直接ダウンロード:**

1. [最新リリース](https://github.com/deadlylaid/DigiTokenBar/releases/latest)から **DigiTokenBar.zip** を
   ダウンロードして展開します。
2. **DigiTokenBar.app** をアプリケーションフォルダに移して開きます。
3. 初回は macOS が「開発元を検証できません」と表示して開きません。DigiTokenBar は無料のファンプロジェクトで、
   Apple の公証を受けていないためです。**システム設定 → プライバシーとセキュリティ** を開き、下の方にある
   DigiTokenBar の **このまま開く**(英語表示では Open Anyway)を押してください。ターミナルで次のコマンドを
   実行しても構いません。

   ```sh
   xattr -dr com.apple.quarantine /Applications/DigiTokenBar.app
   ```

4. Claude Code の公式上限を表示するため、アプリはキーチェーンから Claude Code のログイン情報を読みます。そのため
   macOS が一度確認します。**常に許可** を選んでください。リリースは毎回同じ署名なので、アップデート後も
   そのまま使えます。

**アップデート:** 新しいバージョンが出るとアプリが知らせます。アップデートを押すと、Homebrew で入れたアプリは
自動で更新されます(`brew upgrade --cask deadlylaid/tap/digitokenbar` と同じ)。直接ダウンロードした場合は
リリースページが開くので、新しい `DigiTokenBar.zip` のアプリに置き換えてください。デジモン、セーブ、設定はそのまま残ります。

## 育て方

1. **タマゴを選ぶ。** まだ育てていない系統からタマゴが 3 つランダムに出ます。卒業させたことのある系統は
   いつでも選び直せます。1 日選ばないと自動で決まります。
2. **いつも通りコーディングする。** 200,000 トークンで経験値 1。1 日の上限はなく、使ったトークンはすべて
   経験値になります。タマゴから卒業までは 1 倍で経験値 10,200、1 日 2 億トークンなら 10 日ほどです。
   速さは設定で 0.5 倍、1 倍、1.5 倍、2 倍、5 倍から選べます。使う量が少なければ速く、多ければ遅くしてください。
3. **進化。** 1 つの系統はバイタルブレスのカード 1 枚です。40 系統、636 体のデジモン(アーマー体 22 体を
   含む)がいて、幼年期 I から究極体まで育ちます。進化はそのカードのルートに従い、カードの条件がルートを開きます。バイタル値は
   1 日の平均コーディング時間、トロフィーは良い日(コーディングした日、上限を超えなかった日、ツールを 2 つ
   使った日)、バトル数と勝率はバトルで数えます。開いたルートの中からは確率で 1 つ選ばれ、コーディングの仕方がその確率を傾けます。
   昼に安定して使うとワクチン、多くのツールを何日も使うとデータ、深夜が増えたり上限まで使うとウイルス寄りです。
   今と同じ属性に進むルートは少し出やすくなります。抽選は段階ごとに 1 回だけで、アプリを開き直しても引き直しは
   ありません。条件を何も満たさないとやさしいルートに進みます。
   隠し進化もいくつかあります(バグを 20 匹倒す、使用上限に 3 回達する)。隠し進化を得ると抽選なしでそちらに進みます。
4. **アーマー進化。** 一部の成長期デジモンは、いつも通り育つ代わりにデジメンタルを使ってアーマー体になれます。
   かけら(たまに出る金色のバグ、お客のおみやげ、出席スタンプ、驚きポイント)を集め、同じ種類が 3 つそろうと
   デジメンタルになります。奇跡と運命の黄金のデジメンタルはまれに丸ごと手に入り、段階を飛ばします
   (ブイモン → マグナモン)。
5. **友だちとジョグレス。** カードにジョグレス進化がある段階を満たすと、デジモンは最大 24 時間、友だちの
   コード(バトルコードと同じ)を待ちます。友だちのデジモンがカードに書かれた相手(「ウイルス種の完全体」、
   「エンジェモン」など)に合えばジョグレス進化し、シーンに友だちのデジモンが歩いてきます。コードがないか
   「Evolve without it」を押すと、いつも通り進化します。待つ間の経験値は次の段階に持ち越されます。
   決まった究極体同士のジョグレス(ウォーグレイモン + メタルガルルモン = オメガモン、ほか 10 組)は、
   相手を育てたことも必要です。
6. **卒業。** 究極体を満たすと図鑑に残して卒業し、新しいタマゴが来ます。

## 機能

- **シーン:** デジモンが歩き、眠り、必殺技でバグを倒します。大きなバグは 3 回当てないと倒せません。
  使用上限がいっぱいの間は具合が悪そうに、深夜は眠そうにします。ときどき顔を洗ったり、料理して食べたり、
  小さな壁を登ったり、鼻ちょうちんで昼寝したり、ボールを蹴って遊んだり、コーディングエージェントが動いている間は
  小さなノートパソコンを打ったりします。
- **図鑑:** 系統ごとに段階別に表示します。育てたデジモンだけ絵が出て、残りはシルエットです。隠し進化、
  デジメンタルで進むアーマー体、ジョグレス専用のデジモンにはヒント(必要なデジメンタルや相手)が出ます。
  すべての系統から名前で探し、絞り込み、並べ替えができます。
- **デスクトップペットとメニューバー:** デスクトップ(設定 → デスクトップペット)とメニューバーにデジモンが
  出ます。成長率も表示できます。マウスでなでるとハートが出て、ダブルクリックするとジャンプします。大きさは
  小・中・大から選べます。設定 → Digimon → 「Stay in place」をオンにすると、歩き回らずに真ん中にいます。
- **エージェントへの反応:** Claude Code が作業中はデスクトップペットの頭上に点が点滅し、確認が必要なときは
  吹き出しを出し、終わると喜びます。`sh tools/digimon/install-agent-hooks.sh` を一度実行すれば設定できます
  (`~/.claude/settings.json` を先にバックアップし、既存のフックはそのまま残します)。ほかのエージェントは
  `digitokenbar://agent?state=<working|waiting|done|idle>&label=<名前>` を開けば反応します。
- **バトル:** バトルコードでほかの DigiTokenBar ユーザーと戦えます。自分のコードをコピーしてチャットで送り、
  相手のコードを貼り付けると、両方のアプリで同じバトルが再生されます。サーバーは不要です。1 日 5 回の練習
  バトル(野生のデジモン)も数えます。バトルは経験値をくれず、カードのバトル数・勝率の条件を満たします。
  友だちとのジョグレスにも同じコードを使います。
  コードに入るのはランダムなプレイヤー番号とデジモンの情報だけです。
- **今日:** 毎日「今日の運勢」(晴れ、バグ騒ぎ、闘志、お客の多い日、流星群)が決まり、お客のデジモンが遊びに
  来ます。お客はほとんど自分の図鑑のデジモンで、1% の確率で初めて見るデジモンが来ます(図鑑に「目撃」として
  残ります)。お客に応じて驚きポイントがたまります。コーディングした日ごとに出席スタンプが 1 つ押され、7 つ集めると
  初めて見るとても珍しいお客がすぐに来ます。運は使用量と関係なく、引き直しもできません。
- **セーブ:** 自動バックアップ(起動時と 12 時間ごと、最新 10 個を保持)。エクスポート・インポートで別の Mac に
  移せます。
- **成長速度:** 設定で 0.5 倍、1 倍、1.5 倍、2 倍、5 倍から選べます。新しい速さですでに満ちた段階はすぐ進化します。
- **使用量グラフ:** 今月の日別、直近 16 週、今日の時間別(いつもの一日を薄く重ねて表示)を切り替えられます。
  ポップオーバーを開いたときのグラフは設定で選び、グラフをクリックすると他のグラフを見られます。
- **高速成長(テスト):** 選んだ速さに加えて各段階に必要な経験値を 10 分の 1 にして、すばやく試せます。

デジモンの画面は韓国語と英語のみ対応しています(日本語では英語で表示されます)。

## 対応ツール

Claude Code、Codex、Gemini CLI、Antigravity、OpenCode、Hermes Agent、Cursor、Grok Build CLI、
Copilot CLI、Kiro CLI、Pi Agent、omp、omo、Aside、Kimi Code、Devin CLI。公式の使用上限は Claude Code、
Codex、Antigravity、OpenCode Go、Grok で表示されます。この部分は PokeTokenBar と同じです。各ツールの
使用量をどこから読むかは、元の README の[データソース](https://github.com/chattymin/PokeTokenBar/blob/main/README.ja.md)を
ご覧ください。

## ソースからビルド

macOS 14 以降、Swift 6 を含む Xcode が必要です。

```sh
bash scripts/create-signing-cert.sh            # 初回のみ: この Mac 専用の署名証明書。再ビルドしてもキーチェーンの「常に許可」が保たれます
PTB_NATIVE_ARCH_ONLY=1 bash scripts/build-app.sh  # ビルドして /Applications/DigiTokenBar.app にインストール
swift test --parallel                          # テスト
```

## デジモンデータの出典

- **デジモンと進化:** [Wikimon](https://wikimon.net)(テキストは CC BY-SA 3.0)。`tools/digimon/build_data.py` と
  `gen_catalog.py` で生成します。
- **カードごとの進化ルート**(カードにどの進化があり、どれがジョグレスか): 機器をまとめたファン資料、主に
  humulos.com。調査記録は `tools/digimon/research` にあります。
- **必殺技と韓国語名:** 公式の韓国語デジモン図鑑(digimon.net/reference_ko)。
- **画像はこのリポジトリにもアプリにも含まれていません。** アプリが実行中に wikimon.net から取得し、
  `~/Library/Application Support/DigiTokenBar/digimon-sprites` に保存します。

## プライバシー

- トークン使用量は Mac の中で読むだけで、どこにも送信しません。
- 外部への接続: 画像を取得する wikimon.net、PokeTokenBar にもともとある公式上限・障害情報の確認、そして
  アップデート確認のためのこのリポジトリの GitHub 最新リリース情報です。PokéAPI からは何も取得しません。
- Claude Code のフックは、インストールスクリプトを自分で実行したときだけ入ります。
- デジモンのセーブとバックアップは `~/Library/Application Support/DigiTokenBar/` にあります。
