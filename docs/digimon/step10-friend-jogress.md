# 친구와 합체 진화 (2026-11-14)

친구의 코드로 합체(조그레스) 진화를 한다. 카드에 있는 합체 진화 352개와 궁극체끼리 합체 10쌍이 대상이다. 지금까지 합체로만 되는 진화는 잠겨 있었다.

## 사용자 결정

| 질문 | 결정 |
|---|---|
| 언제 합체하나 | **단계 경험치를 다 채운 뒤**에 합체를 시도할 수 있다 |
| 궁극체끼리 합체(오메가몬 등) | **짝을 키워 본 적이 있고**, 그 짝을 가진 **친구의 코드**도 받아야 한다. 예전에는 키워 본 적만 있으면 저절로 합체했다 |

## 짝 조건 데이터

- 카드 조사(`tools/digimon/research/vb-conditions-*.json`)에서 합체 진화마다 짝을 읽는다(`gen_catalog.jogress_partner`).
  - "Jogress with Vaccine or Free Adult" → 속성(백신·프리)과 단계(성숙기).
  - "Jogress with Angemon" → 그 디지몬. 4개가 이렇다(토우몬, 실피드몬).
  - "Stage 15 cleared, Jogress with ..."의 모험 모드 부분은 쓰지 않는다.
  - 읽을 수 없는 문구가 있으면 생성기가 멈춘다.
- 줄기마다 `DigimonLine.jogress`에 들어간다. 34줄기에 352개다. "능력치 또는 합체" 진화의 합체 쪽도 포함한다.
  - 2026-11-19: 363개. 조사 자료가 "모험 15단계 + 합체" 11개를 모험 모드 경로로 적어서 빠져 있었다(WORKLOG).
- 모든 합체 진화에 맞는 짝 디지몬이 카탈로그에 1종 이상 있다. 한 디지몬에서 같은 짝으로 갈 수 있는 결과는 많아야 하나라서, 친구의 디지몬이 결과를 정한다. 두 가지 모두 테스트로 지킨다.
- 궁극체끼리 합체 10쌍은 예전처럼 `specialJogress`에 있다.

## 규칙 (`EvolutionEngine`)

- 단계 경험치를 다 채웠을 때 합체 진화가 있으면 **바로 진화하지 않고 최대 24시간 기다린다**(`GrowthRules.jogressWait`, `JogressWait`). 알림이 온다.
  - 궁극체는 짝을 도감에 가진 합체가 있을 때만 기다린다. 없으면 예전처럼 졸업한다.
- 기다리는 동안:
  - 친구 코드를 붙여 넣으면(`jogress(_:code:at:)`) 친구의 디지몬이 짝 조건에 맞는지 본다. 맞으면 그 결과로 진화한다(`.jogressed` 이벤트).
  - 코드는 배틀 코드와 같다. 망가진 코드, 7일 지난 코드, 내 코드, 이미 합체에 쓴 코드는 거절한다.
  - "합체 없이 진화"를 누르면(`skipJogress`) 평소처럼 진화한다.
  - 24시간이 지나면 평소처럼 진화한다(`tick`).
- 기다리는 동안 쌓인 경험치는 버리지 않고 다음 단계로 넘긴다. 다만 다음 단계가 한 번에 차지 않게, 한 단계 몫 미만까지만 쌓는다(단계 문턱이 뒤로 갈수록 커서 이걸로 충분하다).
- 기다림은 저장 파일에 남아서 앱을 다시 켜도 이어진다. 예전 저장 파일은 그대로 읽힌다.
- `EvolutionRules.friendJogress = false`로 끄면 예전 방식이다(합체 진화는 잠김, 궁극체끼리 합체는 저절로).

## 화면

- **홈**: "친구와 합체할 수 있어요" 칸. 남은 시간, 필요한 짝과 결과("바이러스 완전체 → ???", 안 만난 결과는 ???), "받은 코드로 합체", "합체 없이 진화"(궁극체는 "합체 없이 졸업"), 설명이 나온다. 진행 막대 제목은 "친구의 합체 코드를 기다리는 중"이고, 숫자는 막대를 넘지 않게 보여 준다.
- 친구는 배틀 칸의 "내 코드 복사"로 코드를 만든다.
- **장면**: 친구의 디지몬이 반대쪽에서 나타나고, 둘이 가운데로 걸어와 만나 점점 빠르게 깜빡이고(진화처럼 밝은 화면에서는 어두운 그림자), 번쩍인 뒤 진화 연출이 이어진다. 처음 그려 보니 흰 그림자가 밝은 하늘에 묻혀서 진화와 같은 그림자로 바꿨다.
- **도감**: 합체로만 만나는 디지몬의 힌트가 "친구와 합체해야 만날 수 있어요: 브이드라몬 + …"처럼 필요한 짝을 알려 주고, 사람 둘 표시가 붙는다. 그 합체 진화도 진화 전·후에 나온다. 궁극체끼리 합체 힌트는 친구 코드가 필요하다고 바뀌었다.
- 알림: 기다림이 시작될 때, 합체했을 때("워그레이몬 + 메탈가루몬 → 오메가몬").

## 확인한 것

- 전체 테스트 통과(아래 커밋 기준).
- 새 테스트: `DigimonJogressTests` 15개(짝 데이터, 짝 판정, 기다림, 합체, 맞지 않는 짝, 내 코드·쓴 코드·망가진 코드·지난 코드, 기다림 없을 때, 시간 초과, 건너뛰기, 경험치 넘기기, 저장, 궁극체끼리 합체, 끈 경우), 저장소 테스트 2개, 장면 테스트 1개. 예전 오메가몬 테스트와 도감 테스트는 새 규칙에 맞게 바꿨다.
- 규칙 10가지를 하나씩 일부러 망가뜨려 모두 테스트가 실패하는 것을 봤다.
- 영역 커버리지(`llvm-cov --show-regions`)로 안 돈 곳을 찾았다. 마감 시각이 없을 때는 테스트에 확인을 더했다. 나머지 둘(코드의 디지몬이 카탈로그에 없을 때, 진화가 부화로 나올 때)은 앞 단계가 이미 막아서 일어날 수 없어, 확인 코드를 지웠다. 같은 짝으로 갈 결과가 여러 개일 때 고르는 코드도 데이터에 그런 경우가 없어서 지우고, 대신 그런 데이터가 생기면 실패하는 테스트를 넣었다.
- 화면 밖에서 그려 봤다: 홈의 합체 칸(한국어·영어), 워그레이몬과 메탈가루몬의 합체 장면.
