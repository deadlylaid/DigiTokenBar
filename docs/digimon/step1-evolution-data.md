# 1단계: 기기 진화표에서 갈래 모으기

정리일: 2026-11-08 · 데이터: `tools/digimon/data/evolutions.json`

## 한 줄 결론

갈라지는 진화를 허용하면 **64×64 그림이 있는 성장기 66종 중 65종을 만들 수 있다.** 64종은 궁극체까지 가고, 그 진화표에 들어가는 디지몬은 모두 **520종**이다. MVP는 바이탈 브레이슬릿 **아구몬 카드 + 파피몬 카드 = 32종**을 추천한다.

## 진화 데이터는 어디서 왔나

Wikimon(https://wikimon.net)에서 받았다. 글은 CC BY-SA 3.0이라 출처를 표기한다. 그림 파일은 받지 않았고, 파일 이름 목록만 쓴다.

| 출처 | 얻은 것 |
|---|---|
| 컬러판 기기 문서 14개 (디지몬 컬러판 Ver.1~5·크로스워즈 15주년, 펜듈럼 컬러판 1~7·ZERO) | 기기별 진화표. 정해진 형식(`VPetEvo` 틀)이라 단계, 속성, "어디서 진화하는지", 조그레스 여부가 다 적혀 있다. |
| 디지몬별 문서 약 900개 | "어디서 진화하나 / 어디로 진화하나" 목록. 항목마다 출처(기기·작품)가 달려 있어서 **바이탈 브레이슬릿·컬러판 기기에서 나온 진화만** 골랐다. 정보 칸에서 대표 단계, 속성, 한국어 이름도 얻는다. 굵은 글씨 항목은 애니 대표 진화로 표시했다(`canon`). |
| 바이탈 브레이슬릿 카드 목록 문서 | 카드 57장과 카드별 수록 디지몬. 카드 한 장이 하나의 진화표다(보통 17종). |

- DAPI는 쓰지 않았다. DAPI는 이 디지몬별 목록을 가져가면서 출처를 버려서, 어느 기기의 진화인지 알 수 없기 때문이다.
- 진화 관계 2,648개 가운데 출처가 바이탈 브레이슬릿인 것과 컬러판 기기인 것만 남겼다.

## 결과

| 항목 | 수 |
|---|---|
| 64×64 그림이 있는 성장기 (Wikimon 대표 단계 기준) | 66 |
| 그중 성숙기 이상까지 갈래가 이어짐 (단계마다 64×64 있음) | **65** |
| 그중 궁극체까지 | 64 |
| 이 진화표 전체에 들어가는 디지몬 | **520** |
| 만들 수 없음 | 웃코몬 (그림 있는 성숙기 갈래가 없음) |

- 대표 줄 하나만 봤을 때는 41종이었다(별도 테스트 앱(이 저장소 밖)의 "만들 수 있는 디지몬 조사").
- 갈래를 허용하니 가지몬, 기자몬, 울퉁몬, 톱니몬 등도 다 들어왔다.

## MVP 추천: 아구몬 카드 + 파피몬 카드 (32종)

바이탈 브레이슬릿 카드 2장이다. 두 카드에 아르고몬과 오메가몬이 겹쳐서 17 + 17 − 2 = 32종이다. 기준 문서의 MVP 30~50종 안에 들어간다.

추천 이유는 이렇다.
- 카드 한 장이 기기에서 실제로 쓰인 진화표라 갈래가 자연스럽다.
- 그림이 모두 같은 기기 그림이라 그림체가 맞는다.
- 테스트 앱의 아구몬·파피몬과 이어진다.
- 오메가몬이 두 카드에 함께 있어서, 나중에 조그레스(워그레이몬 + 메탈가루몬)를 확장할 첫 예시로 좋다.

표에서 ★는 메뉴바용 컬러판 그림이 없어 64×64를 줄여 쓰는 디지몬이다(32종 중 8종).

**아구몬 카드**

| 단계 | 디지몬 |
|---|---|
| 유년기 1 | 깜몬 |
| 유년기 2 | 코로몬 |
| 성장기 | 아구몬 |
| 성숙기 (4갈래) | 그레이몬, 아르고몬★, 우가몬, 실리컨몬 |
| 완전체 (6) | 메탈그레이몬, 안드로몬, 스콜피오몬, 콩알몬, 네오데블몬★, 메탈티라노몬 |
| 궁극체 (4) | 워그레이몬, 블리츠그레이몬, 단데블몬★, 오메가몬 |

**파피몬 카드**

| 단계 | 디지몬 |
|---|---|
| 유년기 1 | 푸니몬(Punimon) |
| 유년기 2 | 뿔몬 |
| 성장기 | 파피몬 |
| 성숙기 (4갈래) | 가루몬, 고릴라몬★, 스파이더몬, 아르고몬★ |
| 완전체 (6) | 워가루몬, 밸브몬, 빅콩알몬, 패롯몬★, 데블시드라몬★, 오로치몬★ |
| 궁극체 (4) | 메탈가루몬, 크레스가루몬, 니즈헤그몬★, 오메가몬 |

- 성숙기 → 완전체 → 궁극체 사이는 거의 모든 조합이 이어진다. 예를 들어 그레이몬은 완전체 6종 중 5종으로 갈 수 있다.
- 그래서 어느 갈래로 갈지가 2단계에서 정할 "진화 조건"의 몫이다.
- 정확한 연결은 `python3 -I tools/digimon/report.py --cards`와 데이터 파일로 볼 수 있다.

다른 카드 후보도 있다. 카드마다 성장기에서 궁극체까지 진화표가 대부분 완성돼 있다.
- 길몬, 테리어몬, 레나몬, 감마몬, 젤리몬, 앙고라몬 카드
- 펄스몬 카드(Impulse City), 팔몬 카드(Hermit in the Jungle)
- 목록 전체는 `report.py --cards` 결과에 있다.

## 데이터 형식 (`tools/digimon/data/evolutions.json`)

- `nodes`: 디지몬별 정보
  - `name` (Wikimon 문서 이름), `ko` (한국어 이름), `level` (대표 단계), `levels` (작품별 단계 전부), `attributes`
  - `sprites`: 그림 파일 이름. `vb` = 64×64, `dmc`·`dpc` = 메뉴바 컬러판
- `edges`: `from` → `to`, `sources`, 그리고 있으면 `canon`(애니 대표), `jogress`, `warp`
  - `sources` 값: `VB` = 바이탈 브레이슬릿, `DMC`·`DPC` = 컬러판 기기. `DMC:<문서>`는 기기 진화표에서 직접 읽은 것
- `cards`: 바이탈 브레이슬릿 카드 이름, 일본 출시일, 수록 디지몬

## 다시 만들기

```bash
python3 -I tools/digimon/fetch_wikimon.py    # Wikimon 문서 받기 (.cache/, git에 안 들어감). 이미 받은 건 건너뜀
python3 -I tools/digimon/build_data.py       # 진화 데이터 만들기
python3 -I tools/digimon/report.py --cards   # 만들 수 있는 수와 카드별 진화표
```

- `--refresh`: 문서를 전부 다시 받는다.
- `--refresh-images`: 그림 파일 목록(약 7만 8천 개)도 다시 훑는다. 그림 목록 스냅샷을 새로 받을 때 쓴다.

## 알려진 빈틈

- **이름 짝 맞추기:** 그림 파일 이름과 문서 이름이 다른 경우를 규칙으로 맞췄다. 예: "Mode", "Anime Version", X항체, "ö" 같은 특수문자. 그래도 남은 게 있다.
  - 헉몬 계열(Dragonic Blaze 카드), 젤리몬 배틀 형태, 일부 X항체
  - 메다로트 콜라보 카드의 디지몬이 아닌 캐릭터
- **카드 출시일:** 일부 카드는 표의 날짜 칸 형식이 달라서 비어 있다.
- **푸니몬** 등 한국어 이름이 없는 디지몬은 영어 이름으로 둔다.
- **바이탈 브레이슬릿의 진화 조건:** 기기에서 진화를 가르는 실제 조건(훈련, 배틀 승률 등)은 이 데이터에 없다. 우리 진화 조건은 토큰 사용 방식으로 새로 정한다(기준 문서 원칙 5번: 진화 데이터와 진화 조건 분리).
