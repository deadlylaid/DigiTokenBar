# 오락성 평가: 원본 PokeTokenBar 대비 (2026-11-19)

원본의 오락성을 10개 기준으로 나누고, **원본을 모든 기준 50점**으로 두었다. 그 기준에서 DigiTokenBar를
1~100점으로 매겼다. 평가 시점은 줄기 40개, 디지몬 614종(`9ccdd50`)이다.

## 방법과 한계

- 기능과 코드를 보고 매겼다. 실제로 몇 주 써 보며 잰 것이 아니다.
- 원본 쪽 근거는 원본 README(`upstream/main`)와 코드다. 디지몬판 쪽 근거는 README, 코드, 생성된 카탈로그다.
- 기준마다 비중이 같다. 메뉴바 앱의 핵심을 "가끔 열어 봤을 때의 작은 놀람과 보상"으로 보면 약한 쪽(9, 10)의
  비중이 더 크다. 그렇게 따지면 체감 점수는 평균보다 낮을 수 있다.

## 올릴 곳 (우선순위 제안)

1. **보상 루프(15):** 한도를 채웠을 때 벌칙 대신 보상. 원본의 사탕처럼 막히는 순간이 성장으로 이어지게.
2. **운·놀람(25):** 드문 개체나 드문 진화.
3. **수집 장치(40):** 줄기별 완성 표시(몇 종 중 몇 종), 도감 검색·필터.
4. **직접 만지는 재미(40):** 쓰다듬기 같은 작은 반응, 펫 크기 조절.

1과 2만 40점대로 올려도 평균이 50점을 넘는다. 아직 정한 것은 없다. 상점·업적은 원래 "MVP를 일주일 써 보고
정한다"(WORKLOG 다음에 할 일)로 미뤄 둔 상태다.
