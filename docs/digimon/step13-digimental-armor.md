# 13단계: 디지멘탈과 아머 진화 (보상 루프)

정리일: 2026-11-21 · 상태: **A안으로 만들었다(사용자 결정, 2026-11-21).** 아머체 데이터(5), 조각 보상 루프(6), 디지멘탈로 아머 진화(7). 조각 숫자는 제안대로. **그 뒤 디지멘탈은 성장기에서만 쓰도록 바꿨다(8, 원작에 가깝게).** 5·7절의 32개 경로·11종·브이드라몬 예는 8절이 대신한다.

오락성 평가에서 가장 낮은 두 칸이 보상 루프(15점)와 운·놀람(25점)이다(`fun-evaluation.md`). 놀람 점수는 쌓이기만 하고 쓸 곳이 없다(`step12-luck.md` 4). 이 단계는 "모으고 → 쓰고 → 새 디지몬이 된다"는 고리를 만든다.

## 1. 원작에서 확인한 것

| 출처 | 디지멘탈 얻기 | 아머 진화 |
|---|---|---|
| D-3 장난감(2000) | 안테나로 "탐색"해서 찾는다 | 배틀 중에 한 번, 아무 디지멘탈이나 쓸 수 있다. 성장기 6종(브이몬·추추몬·호크몬·가트몬·아르마몬·파닥몬)마다 약 10가지 |
| 애니메이션(02) | 정해진 장소에서 줍는다 | 성장기 → 아머체, 싸움이 끝나면 되돌아온다 |
| 바이탈 브레이슬릿 카드 | 없음 | 아머체가 **보통 진화 한 단계**다(예: 아르마몬 → 디그몬 → 홀리엔젤몬). 지금은 "아머체 빼기" 규칙으로 잘라 놓았다 |

- 디지멘탈 진화표(Wikimon "Digimental Evolution Chart", 145쌍)를 우리 데이터와 맞췄다.
  - 우리 도감에 있는 성장기가 바탕이고, 바이탈 브레이슬릿 그림이 있는 아머체로 가는 쌍은 30개(아머체 21종, 성장기 13종, 40줄기 중 12줄기)다.

## 2. 정할 것: 아머 진화를 어떻게 넣을까

### A안 (추천): 카드 경로를 되살리고 디지멘탈로 연다

- 위 표의 17개 경로를 줄기에 되살린다. 디지멘탈이 있어야만 열린다.
- 성장기 단계를 다 채웠을 때 맞는 디지멘탈이 있으면, 홈에 "용기의 디지멘탈로 아머 진화 / 그냥 진화"가 뜬다.
  - 24시간 안에 고르지 않으면 그냥 진화한다. 지금의 "친구 합체 기다리기"와 같은 방식이다.
- 아머체는 성숙기 자리를 그대로 산다(약 하루 반). 그 뒤 카드가 정한 완전체로 이어 진화한다.
- 디지멘탈은 **쓰면 사라진다.** 그래서 조각을 계속 모을 이유가 생긴다.
- 도감: 10개 줄기의 성숙기 칸에 아머체 13종이 들어간다(도감 총수 614 → 627). 못 만난 아머체에는 "○○의 디지멘탈이 있으면" 힌트가 붙는다.
- 좋은 점: 원작 카드 그대로다. 디지몬의 생애가 실제로 달라진다. 새 디지몬 13종을 만난다.
- 아쉬운 점: 아머 진화가 되는 줄기는 10개(40개 중)다. 진화 데이터 생성기를 고쳐야 해서 작업이 크다.
- 쓰는 디지멘탈은 8종(용기, 우정, 사랑, 지식, 순수, 성실, 희망, 빛)이다.

### B안: 성장기일 때만 잠깐 변신 (D-3·애니 방식)

- 진화표의 30쌍(아머체 21종, 12줄기)을 쓴다. 성장기일 때 디지멘탈을 쓰면 아머체로 변신하고, 언제든 되돌린다.
- 진화 길은 그대로다. 펫·메뉴바·배틀에 아머체로 나오고, 도감에 따로 "아머체 n/21" 칸이 생긴다.
- 디지멘탈은 계속 쓸 수 있다(한 번 모으면 끝).
- 좋은 점: 작업이 작고, 원작(D-3)의 "아무 디지멘탈이나"에 가깝다.
- 아쉬운 점: 성장기는 생애 약 7일 중 하루쯤이라 쓸 시간이 짧다. 다 모으면 더 모을 이유가 없다.

## 3. 보상 루프 (두 안 공통)

- **디지멘탈 조각:** 조각마다 디지멘탈 종류가 있다. 같은 종류 3개가 모이면 디지멘탈 1개가 된다(D-3의 "조각 3개"를 따름).
- **조각 얻는 곳** (가정: 활동한 날 버그 약 80마리, 손님 약 1번):
  - **황금 버그:** 버그 100마리 중 1마리꼴로 나온다. "버그가 몰려오는 날" 기운이면 2배다. 잡으면 조각 1개를 준다. 하루 약 0.8개.
  - **손님 선물:** 손님 10번 중 1번 조각을 두고 간다. 처음 보는 디지몬은 반드시 두고 간다.
  - **출석 도장 7개:** 원하는 종류의 조각 1개.
  - **놀람 점수 교환:** 5점 → 원하는 종류의 조각 1개. 놀람 점수를 처음으로 쓸 곳이 생긴다.
  - 무작위로 받는 조각은 지금 키우는 디지몬이 쓸 수 있는 종류가 더 잘 나온다.
- **예상 속도:** 하루 약 1개 → 첫 디지멘탈은 약 3일. 일주일에 한 번 돌아오는 성장기에 하나쯤 준비된다.
- **보이는 곳:**
  - 홈 도장 줄 옆에 조각 수.
  - 도감 위쪽에 "디지멘탈" 칸(가진 것, 모으는 중인 조각).
  - 알 고르기와 줄기 메뉴에 "아머 진화 가능" 표시.

## 4. 만들 순서 (A안 기준)

1. 조사 자료 정리: 17개 경로와 아머체의 카드 조건·다음 진화를 humulos에서 다시 모아 `tools/digimon/research`에 둔다. 아머체 한국어 이름·기술 이름은 공식 도감에서 확인한다.
2. 생성기: 아머체를 "디지멘탈 잠금" 경로로 넣는다. 잠금이 없는 아머 경로가 생기면 멈추는 검사를 둔다.
3. 엔진: 조각·디지멘탈 저장, 아머 진화 선택(24시간), 디지멘탈 소모.
4. 장면: 황금 버그, 손님 선물 연출.
5. 화면: 홈 조각 수, 도감 디지멘탈 칸, 아머 진화 선택, 알 고르기 표시, 놀람 점수 교환.
6. 테스트와 기록.

## 5. 만든 것 1: 아머체 데이터 (2026-11-21)

- **규모:** 카드 9장(9개 줄기)에 아머체 20종, 디지멘탈 경로 32개가 들어갔다. 도감 총수는 614 → 634.
  - 젤리몬 카드는 뺐다. 카드 표에 아머체가 없다(위키몬의 젤리몬 → 맘보몬은 다른 기기의 경로).
  - 기존 40개 줄기의 아머체가 아닌 부분(디지몬, 진화, 조건, 합체)은 하나도 바뀌지 않았다. 생성 결과를 전후로 비교해 확인했다.
- **규칙:** 다른 단계의 디지몬에서 아머체로 가는 보통 경로는 **모두** 디지멘탈이 있어야 열린다. 성장 혼자서는 절대 가지 않는다.
  - 설계 때 본 성장기 → 성숙기 아머체 17개보다 넓다. 카드에는 성숙기 → 완전체 아머체(사수몬, 골드브이드라몬, 콩고몬, 푸치몬 2종)와 완전체 → 궁극체 아머체(매그너몬, 래피드몬(아머체))도 있어서 같은 규칙으로 넣었다. 그래서 디지멘탈 11종이 모두 쓰인다.
  - 합체(조그레스)로 아머체가 되는 경로는 디지멘탈 없이 그대로다. 짝이 필요하기 때문이다(예: 스팅몬 + 데이터 성숙기 → 콩고몬).
  - 아머체끼리 이어지는 경로(화염드라몬 → 사수몬)와 아머체에서 다음 단계로 가는 경로는 카드 조건 그대로다.
- **경로마다 디지멘탈:**

| 줄기 | 경로 | 디지멘탈 |
|---|---|---|
| 브이몬 | 브이몬 → 화염드라몬 / 번개드라몬 | 용기 / 우정 |
| 브이몬 | 브이드라몬 → 사수몬, 브이드라몬·엑스브이몬 → 골드브이드라몬, 디지타몬 → 매그너몬 | 희망, 운명, 기적 |
| 추추몬 | 추추몬 → 샤드라몬 | 용기 |
| 추추몬 | 스팅몬·후디에몬 → 푸치몬(녹), 고키몬 → 푸치몬, 고키몬 → 콩고몬 | 상냥함, 상냥함, 기적 |
| 호크몬 | 호크몬·추추몬 → 호루스몬 / 수리몬, 가트몬(성장기) → 네페르티몬 | 사랑 / 순수, 빛 |
| 아르마몬 | 아르마몬 → 디그몬 / 잠수몬, 파닥몬 → 페가수스몬, 브이몬 → 화염드라몬 / 번개드라몬 | 지식 / 성실, 희망, 용기 / 우정 |
| 아르마몬 | 홀리엔젤몬·파일드라몬 → 매그너몬 | 기적 |
| 레나몬 | 레나몬 → 링스몬 | 용기 |
| 테리어몬 | 테리어몬 → 하피몬, 래피드몬·마쿠라몬·파지라몬 → 래피드몬(아머체) | 빛, 운명 |
| 블루코몬 | 블루코몬 → 무스몬 | 희망 |
| 샌드리자몬 | 샌드리자몬 → 디그몬 | 지식 |
| 피요몬 | 팔코몬(2006)·쟈자몬 → 썬더버드몬 | 우정 |

  - 정한 방법: 위키몬 디지멘탈 진화표에 그 디지몬과 그 아머체의 쌍이 있으면 그 칸(10개), 없으면 그 아머체의 대표 디지멘탈(표에서 처음 나오는 칸, 22개).
  - 확인: 공식 도감(digimon.net)의 아머체 설명에 적힌 디지멘탈과 32개 중 31개가 같다. 나머지 1개(잠수몬)는 공식 도감에 없다. 위키몬도 아르마몬 → 잠수몬을 성실의 디지멘탈로 적는다.
- **이름과 필살기:** 공식 한국어 도감 이름과 기술 이름을 썼다(`research/moves-armor.json`). 예외가 둘 있다.
  - **잠수몬:** 공식 도감에 없어서 한국 방송 이름을 썼다. 기술 "옥시젠 호밍"도 위키몬 일본어 이름을 소리대로 적었다. 공개 배포 전에 확인한다.
  - **래피드몬(아머체):** 공식 이름이 완전체 래피드몬과 같은 "래피드몬"이다. 같은 줄기에 둘 다 있어서 "(아머체)"를 붙였다.
  - 필살기 모양은 기존 17가지 중에서 기술이 실제로 어떻게 생겼는지 보고 골랐다(예: 하피몬의 진공 칼날은 할퀴기, 매그너몬의 플라즈마 구슬은 전기).
- **아직 바뀌지 않는 것:** 성장은 디지멘탈 경로를 고르지 않는다(`EvolutionRules.isLocked`).
  - 도감에는 새 실루엣이 방패 표시와 함께 나온다. 힌트는 "용기의 디지멘탈이 있으면 진화할 수 있어요."다.
  - 디지멘탈을 써서 진화하는 일은 다음 단계(합치기)에서 `EvolutionEngine.armorOptions`와 `DigimonLine.digimental(from:to:)`로 한다.
- **뺀 것:** 프런티어 페어리몬 카드의 피콕몬(이번 조사 범위 밖), 블랙 파피몬 카드의 리노몬(이번 카드 목록 밖).
- **기존 테스트에서 바꾼 것:**
  - 도감 수 614 → 634, 합체 경로 수 476 → 515.
  - 합체 전용 표시의 예를 디지타몬(브이몬 줄기) → 토우몬(아르마몬 줄기)으로 바꿨다. 브이몬 줄기의 디지타몬은 이제 화염드라몬·번개드라몬에서도 온다.
  - 도감 검색의 "비밀 없는 줄기 고르기" 테스트는 실제 데이터에 그런 디지몬이 더 이상 없다. 그래서 규칙으로 브이몬 줄기의 두 경로를 잠가 상황을 만들어 둔다.
- **재발 방지:**
  - 생성기는 세 경우에 멈춘다: 디지멘탈 없이 아머체로 가는 보통 경로, 다음으로 갈 길이 없는 아머체, 모르는 디지멘탈.
  - `tools/digimon/check_armor_guards.py`가 자료를 일부러 망가뜨려 세 경우 모두 멈추는지 확인한다.
  - `DigimonArmorTests`도 함께 지킨다. 디지멘탈 잠금을 풀거나 도감 힌트를 빼면 35개 단언이 실패하는 것을 확인했다.

## 6. 만든 것 2: 조각 보상 루프 (2026-11-21)

- **조각과 디지멘탈:** 조각마다 디지멘탈 종류(11종)가 있다. 같은 종류 3개가 모이면 그 자리에서 디지멘탈 1개가 되고, "용기의 디지멘탈을 만들었어요!" 알림이 간다. 디지멘탈은 종류별 개수로 저장한다(아머 진화가 쓰면 줄어든다). 저장 파일의 `digimentals` 칸이고, 예전 저장 파일도 그대로 열린다.
- **조각 얻는 곳:**
  - **황금 버그:** 장면에 나오는 작은 버그 100마리 중 1마리꼴로 금색이다. "버그 소동" 날은 50마리 중 1마리다. 잡으면 조각 1개와 "디지멘탈 조각!" 말풍선이 나온다. 팝오버와 바탕화면 펫이 따로 버그를 내보내서, 하루에 조각을 주는 황금 버그는 3마리까지다.
  - **손님 선물:** 손님 10번 중 1번 조각을 두고 간다. 처음 보는 디지몬은 반드시 두고 간다. 손님이 인사한 뒤 발밑이 반짝이고 펫이 "선물이다!" 한다.
  - **출석 도장 7개:** 도장 판을 다 채우면 선물이 하나 생긴다. 도감에서 "도장 선물 받기"를 눌러 원하는 종류를 고른다.
  - **놀람 점수:** 도감에서 "놀람 5점 → 조각"을 눌러 원하는 종류를 고른다. 놀람 점수가 5점 줄어든다.
- **무작위 종류:** 황금 버그와 손님 선물의 종류는 그날의 운처럼 정해진다(플레이어, 날짜, 몇 번째 황금 버그인지 또는 어느 손님인지). 백업을 되돌려도 같은 종류가 나온다. 지금 디지몬이 쓸 수 있는 종류는 3배 잘 나오게 해 두었다. 다만 그 목록은 아머 데이터가 들어와야 채워진다.
- **보이는 곳:**
  - **홈 출석 도장 줄:** 선물 상자(받을 도장 선물이 있을 때), ◇ 조각 수, ◆ 가진 디지멘탈 수.
  - **도감 맨 위 "디지멘탈" 칸:** 한 줄로 접혀 있다. 펼치면 11종마다 조각 ●●○와 가진 개수 ×n이 보인다. 고르기 단추는 펼쳤을 때, 또는 도장 선물이나 교환할 점수가 있을 때 나온다.
- **아머 진화와 이을 때 할 일:**
  - `EvolutionEngine.fragmentKinds()`를 카드 경로가 쓰는 디지멘탈(8종)로 좁힌다.
  - `EvolutionEngine.preferredDigimentals(for:)`가 지금 디지몬의 줄기에서 그 종에서 나가는 디지멘탈 경로의 종류를 돌려주게 한다.
  - 아머 진화가 디지멘탈을 쓸 때 `DigimentalBag.owned`를 1 줄인다.
- **테스트:** `DigimentalLoopTests` 9개, `DigimentalSceneTests` 2개(실제 장면 스크립트로 황금 버그와 손님 선물 확인).
  - 합치기를 빼면, 교환을 공짜로 만들면, "처음 보는 손님은 반드시" 규칙을 빼면 각각 테스트가 실패하는 것을 확인했다.

## 7. 만든 것 3: 디지멘탈로 아머 진화 (2026-11-21)

- **기다리기:** 지금 디지몬의 단계가 다 찼을 때, 그 디지몬에서 나가는 디지멘탈 경로가 있고 그 디지멘탈을 **가지고 있으면** 바로 진화하지 않고 최대 24시간 기다린다(`GrowthRules.armorWait`). 없으면 기다리지 않는다.
  - 성장기 → 성숙기만이 아니라, 데이터에 있는 성숙기 → 완전체, 완전체 → 궁극체 아머 경로에서도 똑같다.
  - 기다리는 동안 쌓인 경험치는 친구 합체 기다림처럼 다음 단계로 넘어간다(한 단계 분량까지).
- **홈:** "디지멘탈로 아머 진화할 수 있어요" 칸에 경로마다 단추가 하나씩 있다. 남은 시간과 가진 개수(×n)도 보인다.
  - 이미 도감에 있는 아머체는 "용기의 디지멘탈로 화염드라몬", 아직 못 만난 아머체는 "용기의 디지멘탈로 아머 진화"와 실루엣만 보인다(이름을 미리 알려 주지 않음).
  - 단추를 누르면 디지멘탈을 **하나** 쓰고 아머체로 진화한다. 도감, 진화 기록, 진화 연출, "아머 진화!" 알림이 보통 진화처럼 나온다. 아머체는 그다음 카드 경로대로 자란다.
  - "그냥 진화"를 누르거나 24시간이 지나면 평소처럼 진화하고 디지멘탈은 남는다.
  - 기다리기 시작하면 "디지멘탈로 아머 진화할 수 있어요" 알림이 간다.
- **친구 합체와 같이 열릴 때:** 두 기다림은 단계가 찬 그 순간 **함께** 열리고 따로 흘러간다(각자 24시간). 둘 다 닫혀야 평소처럼 진화한다.
  - 디지멘탈을 쓰면 그 자리에서 진화하므로 둘 다 끝난다. 친구 코드로 합체해도 마찬가지다.
  - 한쪽을 건너뛰면 다른 쪽은 계속 기다린다. 그래서 친구 합체가 아직 열려 있으면 홈 단추가 "그냥 진화" 대신 "디지멘탈 쓰지 않기"가 된다.
  - 시간이 지나면 둘 다 같은 때 닫힌다. 한쪽이 다른 쪽을 막는 일은 없다(서로 기다리다 멈추지 않음).
  - 예: 브이드라몬(성숙기)은 희망의 디지멘탈로 사수몬, 친구 합체로 다이노몬·디지타몬이 함께 열린다.
- **조각 연결:**
  - 무작위 조각은 카드 경로가 실제로 쓰는 디지멘탈만 나온다(지금 데이터는 11종 모두 씀).
  - 지금 디지몬이 이번 생애에서 쓸 수 있는 종류(지금 종과 앞으로 자랄 수 있는 종에서 나가는 디지멘탈 경로)는 3배 잘 나온다.
- **보이는 곳:**
  - 알 고르기 칸과 도감 줄기 메뉴에 ◆ 표시: 디지멘탈로 아머 진화할 수 있는 줄기(9개).
  - 도감 디지멘탈 칸: 가진 디지멘탈 중 "이번 단계를 채우면 쓸 수 있어요"(기다리는 중이면 "지금 쓸 수 있어요")와 "나중에 쓸 수 있어요". 가진 것이 없으면 이 디지몬이 쓸 종류를 알려 준다.
- **테스트:** `DigimonArmorEvolutionTests` 13개.
  - 내용: 가질 때만 기다림, 정확히 하나 씀, 건너뛰기·시간 초과는 디지멘탈을 남기고 평소처럼 진화, 아머체가 카드대로 자람, 친구 합체와 함께 열림(네 가지 순서), 예전 저장 파일, 저장소에 저장, 조각 연결 지점, 문구.
  - 일부러 망가뜨려 확인함: 쓰고도 줄지 않게 하면 3개, 없어도 제안하게 하면 11개, "그냥 진화"에 디지멘탈을 잃게 하면 2개가 실패한다.

## 8. 바꿈: 디지멘탈은 성장기에서만 (2026-11-21, 사용자 결정)

위 5·7절은 처음 넣었을 때의 모습이다. 그 뒤 사용자가 원작에 가까운 쪽을 골랐다.

- **왜:** 애니메이션(02)과 D-3 장난감은 **언제나 성장기에서** 디지멘탈로 아머 진화한다. 성숙기·완전체가 디지멘탈을 쓰는 일은 없다. 반대로 바이탈 브레이슬릿 카드는 성숙기·완전체에서 가는 아머체(사수몬, 콩고몬 등)를 디지멘탈 없이 보통 진화로 둔다. 처음 넣은 "성숙기·완전체에서도 디지멘탈"은 어느 원작에도 없었다.
- **지금 규칙:**
  - **성장기 → 아머체**만 디지멘탈이 있어야 열린다. 성장 혼자서는 가지 않는다(5·7절의 기다리기·사용·건너뛰기는 그대로).
  - **성숙기·완전체 → 아머체**는 카드 조건(하루 코딩 시간, 트로피, 배틀)을 채우면 가는 보통 진화다. 디지멘탈을 묻지 않고, 도감 힌트도 디지멘탈이 아니다. 사수몬, 골드브이드라몬, 콩고몬, 푸치몬 2종, 매그너몬, 래피드몬(아머체)이 여기에 든다.
- **빠졌던 두 종을 넣었다(사용자 결정):** 둘 다 성숙기에서 카드 조건이나 친구 합체로 가는 완전체 자리라 보통 진화다.
  - **피콕몬:** 페어리몬 카드(팅커몬 줄기). 코카트리몬·잡초몬에서 조건으로, 페어리몬·아르보르몬에서 합체로 온다. 필살기 "레인보우 샤워"(이미 있던 기술).
  - **리노몬:** 블랙 파피몬 카드(블랙 파피몬 줄기). 드리모게몬·도루루몬에서 조건으로, 가루루몬·도루루몬에서 합체로 온다. 필살기는 "아토믹 버스트"(공식 도감의 두 기술 중 공격인 돌진. 첫 기술 "아인 소프 아우르"는 자기를 감싸는 빛의 방어막이라 장면에 맞지 않음).
- **숫자:** 아머체 22종(도감 634 → 636), 디지멘탈 경로 19개(32 → 19), 디지멘탈 8종(용기, 우정, 사랑, 지식, 순수, 성실, 희망, 빛), ◆ 줄기 9개(그대로; 팅커몬·블랙 파피몬 줄기는 성장기 아머가 없어 ◆ 없음). 진화 1,720 → 1,735, 합체 경로 515 → 523.

| 줄기 | 성장기 → 아머체 | 디지멘탈 |
|---|---|---|
| 브이몬 | 브이몬 → 화염드라몬 / 번개드라몬 | 용기 / 우정 |
| 추추몬 | 추추몬 → 샤드라몬 | 용기 |
| 호크몬 | 호크몬·추추몬 → 호루스몬 / 수리몬, 가트몬(성장기) → 네페르티몬 | 사랑 / 순수, 빛 |
| 아르마몬 | 아르마몬 → 디그몬 / 잠수몬, 파닥몬 → 페가수스몬, 브이몬 → 화염드라몬 / 번개드라몬 | 지식 / 성실, 희망, 용기 / 우정 |
| 레나몬 | 레나몬 → 링스몬 | 용기 |
| 테리어몬 | 테리어몬 → 하피몬 | 빛 |
| 블루코몬 | 블루코몬 → 무스몬 | 희망 |
| 샌드리자몬 | 샌드리자몬 → 디그몬 | 지식 |
| 피요몬 | 팔코몬(2006)·쟈자몬 → 썬더버드몬 | 우정 |

- **상냥함·기적·운명:** 이 세 디지멘탈은 성숙기 이후 경로에만 붙어 있었으므로 이제 쓸 경로가 없다.
  - 무작위 조각, 도장 선물, 놀람 점수 교환에서 더는 나오지 않는다(카드 경로가 쓰는 8종만).
  - 예전 저장 파일에 이미 있는 것은 **그대로 남는다.** 도감 디지멘탈 칸에는 8종과 함께, 가진 것이 있는 종류만 더 보인다. 쓸 곳은 없다. 나중에 애니메이션의 황금 디지멘탈(브이몬 + 기적 → 매그너몬 등)을 넣으면 다시 쓰일 수 있다.
  - **2026-11-22 바뀜(16단계):** 디지멘탈 진화표 경로 7개가 생겨 세 가지 모두 다시 쓰인다. 상냥함은 조각으로 다시 모이고, 기적·운명은 황금 디지멘탈로 통째로만 얻는다. `step16-golden-digimentals.md` 참고.
- **친구 합체와 함께 열리는 경우:** 지금 카드에는 성장기 친구 합체 경로가 없어서, 디지멘탈 경로와 친구 합체가 동시에 열리는 디지몬이 없다(7절의 브이드라몬 예는 이제 보통 진화). 순서 규칙은 그대로 두고, 테스트는 브이몬에 합체 경로를 하나 붙인 만든 자료로 네 가지 순서를 확인한다.
- **재발 방지:**
  - 생성기가 멈추는 경우가 넷이 됐다: 성장기에서 디지멘탈 없이 아머체로 가는 보통 경로, 성장기가 아닌 데서 시작하는 디지멘탈 경로(새로 추가), 다음 길이 없는 아머체, 모르는 디지멘탈. `tools/digimon/check_armor_guards.py`가 넷 다 멈추는지 확인한다.
  - 테스트: 디지멘탈 경로는 모두 성장기에서 시작, 성숙기 아머 경로는 보통 진화(브이드라몬 → 사수몬, 코카트리몬 → 피콕몬, 드리모게몬 → 리노몬), 예전 상냥함·기적·운명이 남고 보이는지.
  - 일부러 망가뜨려 확인함: 브이드라몬 → 사수몬에 디지멘탈을 붙이면 아머 테스트 8개 단언, 그 경로를 막으면 1개, 예전 아이템을 숨기면 1개가 실패한다.
- **조사 자료:** `research/armor-routes.json`을 카드 11장으로 다시 모았다(`research/scripts/armor_routes.py`, 페어리몬 EX·True Shadow Howl 추가). 리노몬의 공식 도감 자료는 `research/moves-armor.json`.
