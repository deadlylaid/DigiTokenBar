# 15단계: 바탕화면 펫 만지기

정리일: 2026-11-22 · 상태: **구현함**

오락성 평가에서 "직접 만지는 재미"가 42점으로 원본보다 낮았다(`fun-evaluation.md`). 원본 펫에는 쓰다듬기, 크기 조절 같은 반응이 있었고, 디지몬판은 끌어서 옮기기와 누르면 공격하기뿐이었다. 사용자 결정(2026-11-22): 펫 만지기를 넣는다.

## 쓰다듬기

- 디지몬 위에서 마우스를 **누르지 않고** 좌우(또는 위아래)로 문지르면 쓰다듬은 것이다.
- 디지몬 머리 위로 하트 3개가 떠오르고, 깨어 있으면 살짝 뛴다. 쓰다듬을 때마다 하트가 나오고, 두 번에 한 번 말풍선이 나온다: "좋아!", "기분 좋아~", "헤헤"를 차례로("Yay!", "That feels nice~", "Hehe").
- 자고 있으면 하트만 나오고 계속 잔다. 알이거나 배틀·진화처럼 바쁠 때도 하트만 나온다.
- **알아보는 방법:** 펫이 이미 0.1초마다 확인하는 마우스 위치를 쓴다. 새로 마우스를 감시하지 않는다(그러면 macOS가 "입력 모니터링" 허락을 묻는다).
  - 최근 1.5초 동안 많이 움직인 쪽(가로 또는 세로)에서 방향이 3번 이상 바뀌고, 모두 30포인트 이상 움직였으면 쓰다듬기다.
  - 3포인트보다 작은 움직임은 손 떨림으로 보고 세지 않는다.
  - 보통 1초쯤 문지르면 반응한다.
  - 한 번 반응하면 4초 동안은 다시 반응하지 않는다.
  - 디지몬 밖으로 나가면 처음부터 다시 센다.
- 한 번 지나가기, 가만히 올려 두기, 손 떨림, 디지몬 옆에서 문지르기는 쓰다듬기가 아니다.

## 크기

- 설정 → 바탕화면 펫에 **크기: 작게 / 보통 / 크게**가 생겼다. 이 Mac에만 저장된다(`digimonDeskPetSize`).

  | 크기 | 배율 | 창 크기(포인트) |
  |---|---|---|
  | 작게 | 1.5배 | 330 × 135 |
  | 보통 | 2배 | 440 × 180 (예전과 같음) |
  | 크게 | 2.5배 | 550 × 225 |

- 장면은 어느 크기에서나 220 × 90칸이고 배율만 바뀐다. 그래서 디지몬이 걸어 다니는 범위, 저장된 디지몬 자리, 클릭 영역, 화면 끝에 놓을 때의 보정이 모든 크기에서 그대로 맞는다.
- 크기를 바꾸면 디지몬의 **발 위치가 화면에서 그대로** 있게 창이 커지거나 줄어든다. 화면 밖으로 나가면 창은 화면 안으로 돌아오고, 디지몬은 놓을 때처럼 그만큼 반대로 움직여 자리를 지킨다.

## 두 번 누르기

- 한 번 누르면 예전처럼 **바로** 공격한다(기다리지 않는다).
- macOS의 더블클릭(시스템 설정의 두 번 누르기 속도와 거리)으로 이어진 두 번째 누름은 공격 대신 **점프**한다. 그보다 빠른 세 번째, 네 번째 누름도 점프다.

## 심심해하기

- 바탕화면 펫을 **20분 동안 만지지 않으면**(쓰다듬기, 누르기, 끌기 없음) 가끔 하품하듯 기지개를 켜고, 드물게 "심심해…"("So bored…") 말풍선을 띄운다.
  - 다음 행동을 고를 때마다 12% 확률로 하품하고, 그중 25%에 말풍선이 붙는다.
- 잠잘 때, 졸림·아픔 기분일 때(그때는 원래 반응이 있다), 팝오버 장면에서는 하지 않는다. 제자리에 있기에서도 자리를 옮기지 않는다.
- 쓰다듬기, 누르기, 끌기, 놓기 중 하나라도 하면 20분을 처음부터 다시 센다.

## 전기 사용

- 새 타이머는 없다. 쓰다듬기는 원래 있던 0.1초 위치 확인을 그대로 쓰고, 하트와 하품은 원래 돌던 장면 그리기에서 그린다.

## 확인한 것

- 새 테스트 12개(`DigimonPetTouchTests.swift`):
  - 쓰다듬기: 1초쯤 문지르면 반응, 위아래도 반응, 한 번 지나가기·가만히·손 떨림은 반응 안 함, 디지몬 밖에서는 반응 안 함, 나가면 다시 셈, 4초 쉼.
  - 크기: 세 크기의 창 크기, 이 Mac에 저장, 모르는 값은 보통, 크기를 바꿔도 발 위치 그대로, 크기마다 놓기 보정.
  - 장면: 크기마다 배율과 220칸, 놓기 보정이 배율로 바뀌는지, 하트·뛰기·말풍선, 자면 하트만, 19분에는 안 심심하고 21분에는 하품과 "심심해…", 누르면 다시 셈, 졸린 기분이면 안 함.
- 일부러 망가뜨려 테스트가 실패하는 것을 확인했다:
  - 쓰다듬기가 방향 바꿈을 무시하게 하면 3개가 실패한다.
  - 놓기 보정이 크기를 무시하고 늘 2배로 계산하게 하면 크기 테스트가 실패한다.
- 세 크기로 그레이몬을 그려 하트와 말풍선을 눈으로 확인했다.
- 전체 테스트 1,347개 통과.
