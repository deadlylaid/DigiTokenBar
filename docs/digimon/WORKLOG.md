# 디지몬 토큰바 작업 기록

PokeTokenBar를 바탕으로 디지몬판을 만드는 작업의 날짜별 기록이다. 단계별 세부 내용은 각 문서에 있고, 여기는 흐름과 결정만 모은다.

## 지금 상태 (2026-11-25)

- **끝난 것:** 0~4단계(구조 파악, 진화 데이터·엔진, 화면 연결, 도감과 저장), 성향·기분, 카드 진화 조건, 배틀, 친구와 합체, 제자리에 있기, 줄기 40개(1차 28장 + 2차 중 프런티어 6장), 운·놀람 1단계(오늘의 기운, 손님, 출석 도장), 도감 검색, 디지멘탈과 아머 진화(13단계), 확률 진화(14단계), 펫 만지기(15단계), 황금 디지멘탈(16단계), 하루 상한 없애기와 성장 속도(17단계)
- **규모:** 줄기 40개, 디지몬 636종(아머체 22종 포함), 진화 1,741개, 카드의 합체 진화 523개, 디지멘탈 경로 26개(성장기에서만: 카드 19개 + 디지멘탈 진화표 7개, 디지멘탈 11종 = 조각 9종 + 황금 2종), 궁극체끼리 합체 11쌍
- **다음:** 디지멘탈·아머 진화를 써 보며 숫자 다듬기, 친구 행운(`step12-luck.md` 8). 줄기 추가는 끝났다(아기가 2마리인 카드 2장은 넣지 않기로 함).
- **저장소:** https://github.com/deadlylaid/DigiTokenBar (공개, 2026-11-23부터). 작업은 브랜치에서 하고 `main`에 그대로 이어 붙인 뒤 올린다(PR 없음). 작업 브랜치도 기록용으로 올려 둔다.
- **포켓몬 코드:** 지웠다(2026-11-20). 앱 언어는 이제 포켓몬 세이브가 아니라 앱 설정(`appLanguage`)에 있다.
- **테스트:** 1,383개, 실패 0 (병렬 실행)
  - 실행 명령: `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test --parallel`

## 날짜별 기록

### 2026-11-07: 아이디어와 테스트 앱

- PokeTokenBar의 디지몬판을 만들 수 있는지 검토했다.
- **그림 출처:** 결론은 Wikimon의 V-Pet 기기 도트다.
  - 16×16 컬러판만 쓴 데모는 너무 거칠어 보였다.
  - 64×64 바이탈 브레이슬릿 도트에 코드로 움직임을 붙이니 훨씬 나았다.
- **테스트 앱:** 별도 테스트 앱(이 저장소 밖)을 만들었다.
  - 메뉴바, 팝오버, 바탕화면 펫이 있다.
  - 아구몬·파피몬 두 줄이 Claude Code 토큰 사용량을 먹고 진화한다.
  - 끌어 옮기기, 공격과 진화 단계별 기술 이름(공식 한국어 도감 표기), 버그 잡기를 넣었다.
- **결정:** 디지몬 캐릭터를 새로 그리지 않는다. 기존 도트를 쓴다.

### 2026-11-08: 조사, 기준, 0·1단계

- **만들 수 있는 디지몬 조사**(대표 줄 하나 기준): 64×64만 있으면 되는 기준으로 성장기 41종이었다.
- **사용자 의견:** 디지몬은 진화가 여러 갈래로 갈라지므로, 이후 갈래 진화를 전제로 바꿨다.
- **기준 문서 검토** (`criteria.md`)
  - 1,000종 목표는 "구조만 무제한"으로 바꿨다.
  - 재화·상점·업적은 MVP 이후로 미뤘다.
  - 토큰은 경험치에만 쓰고 하루 상한을 둔다.
  - DAPI는 후보 수집용으로만 쓴다.
- **배포 방향:** 개인용으로 먼저 쓰고, 재미있으면 공개한다.
  - 그래서 처음부터 디지몬 그림을 앱과 저장소에 넣지 않는 구조로 간다.
- **Wikimon 그림 갱신 확인**
  - 64×64는 2024-03 이후 추가가 없다.
  - 컬러판은 2026년에도 계속 늘고 있다.
- **0단계** (`08ade9c`)
  - PokeTokenBar를 비공개 저장소로 옮겼다. 공개 저장소의 포크는 비공개가 안 된다. 원본은 `upstream`으로 연결하고 올리기는 막았다.
  - 연결 지점은 `updateCompanion()`과 `onStoreRefreshed()` 두 곳이다.
  - 원본 앱이 실제로 토큰을 읽는 것을 확인했다. 원본 앱이 남긴 흔적 두 곳은 지웠다.
- **1단계** (`8c56b57`)
  - Wikimon 디지몬 문서의 진화 목록 중 출처가 바이탈 브레이슬릿·컬러판 기기인 것만 모았다.
  - 결과: 64×64가 있는 성장기 66종 중 65종을 만들 수 있고, 전체 520종이다.
  - MVP는 아구몬 카드 + 파피몬 카드 = 32종으로 정했다.

### 2026-11-09: 개발 환경, 2단계, 테스트 정리

- **개발 환경**
  - macOS 27.2와 Xcode 27.2(Swift 6.4.2)를 쓴다. 최신 Xcode는 macOS 15.6에 설치되지 않는다.
  - 테스트는 `DEVELOPER_DIR`로 Xcode를 지정해서 돌린다.
- **원본 테스트 기준점** (`fb364a2`)
  - 1,897개 중 확인 실패 8건이었다. 모두 macOS 27에서 깨지는 포켓몬 화면 테스트 2개에서 났다.
- **2단계 진화 엔진** (`51bf994`)
  - 설계안 세 가지는 제안대로 확정했다.
    - 경험치: 20만 토큰당 1, 하루 150, 한 줄에 활동일 약 10일
    - 갈래: 후보 3개 중 고르고, 24시간이 지나면 자동
    - 새벽 비중은 평소와 비교
  - 숨겨진 진화(버그 20마리 / 한도 3회)를 넣고, 오메가몬은 잠갔다.
  - 테스트 18개를 썼다. 안전장치 3개를 일부러 망가뜨려 테스트가 잡는 것을 확인했다.
- **포켓몬 전용 테스트 정리** (`45d75d5`)
  - 41개 파일과 일부 함수, 테스트 572개를 지웠다.
  - 사용량 장부·저장·바탕화면 펫 창 테스트는 남겼다.
  - 결과: 1,342개, 실패 0. 실행 483초 → 313초(−35%), 빌드 38초 → 32초(−16%).
- **커밋 정리:** 모든 커밋에서 Claude 공동 작업 표시를 지우고 GitHub에 덮어썼다. 앞으로도 넣지 않는다.

### 2026-11-10: 3단계 화면 연결

- **앱 이름 분리** (`811e1c5`): DigiTokenBar 이름·번들 ID·저장 폴더로 바꿨다. PokeTokenBar와 같이 깔아도 섞이지 않는다.
- **디지몬 저장소** (`fb89602`): 원본 사용량 장부를 옮겼다. 한도를 새로 채우면 돌봄 실수로 센다. 사탕은 없다.
- **그림 받기** (`5fa3007`): Wikimon에서 처음 필요할 때 받고, 30일마다 바뀌었는지 확인한다. 앱 안에 디지몬 그림은 없다.
- **화면 연결** (`e2a72b0`): 메뉴바(컬러판 2프레임), 팝오버 홈(펫 화면, 경험치, 진화 선택 카드), 바탕화면 펫(끌기, 누르면 공격), 알림을 붙였다. 상점·가방·도감 탭은 숨겼다.
- **실제 실행**: `/Applications/DigiTokenBar.app`에 설치해 켰다. 설치하기 전에 쓴 그날의 토큰은 경험치로 세지 않고 시작점으로만 잡혔다.
- **함정 두 개**: 둘 다 테스트로 막았다. 자세한 내용은 `step3-wire-up.md`에 있다.
  - 관찰하는 값을 제자리에서 고치면 메뉴바와 무한 반복이 된다.
  - 바탕화면 펫이 앱 밖 마우스를 지켜보면 macOS가 "입력 모니터링" 권한을 묻는다. 지금은 마우스 위치를 직접 읽는다.
- **테스트**: 1,363개, 실패 0.

### 2026-11-10: 4단계 도감과 저장

- **3단계 마무리**
  - 설정의 포켓몬 항목을 숨겼다. "문제 알리기"는 원본 개발자에게 메일이 가서 숨겼다.
  - 앱 아이콘을 코드로 그린 알로 바꿨다.
  - 32종 모두 공식 한국어 도감의 기술 이름을 넣었다. 조사는 다른 에이전트에게 맡겼다.
- **서명 인증서**: 인증서 스크립트와 빌드 스크립트의 인증서 이름이 달라서 맞췄다(`6b58b56`). 인증서를 만들고 팝오버에서 한 번 허용하면 Claude 한도가 읽힌다.
- **도감 탭**: 줄기별·단계별로 보여준다. 못 만난 디지몬은 실루엣, 숨겨진 진화는 힌트로 나온다. 졸업 기록도 있다.
- **알 고르기**: 부화 전까지 아구몬 알과 파피몬 알 중에서 고른다.
- **백업**: 12시간마다 최근 10개를 남긴다. 내보내기·불러오기·되돌리기가 된다. 밖에서 들어온 숫자는 한 곳에서 자른다.
- **빠른 성장**: 테스트용 스위치를 설정에 넣었다. 켜면 필요 경험치가 1/10이다.
- 자세한 내용은 `step4-dex-save.md`에 있다.

### 2026-11-11: 브랜치 합치기, 테스트 시간

- **main 합치기**: 0~4단계 브랜치를 `main`에 fast-forward로 합쳤다(`7dc9991`까지 15개 커밋). 단계별 브랜치는 기록용으로 남겨 두었다.
- **테스트 시간**: `--parallel`로 전체 테스트가 약 70초가 됐다. 아래 참고에 있다.

- **Claude Code 연결**: 작업 중엔 점 세 개, 입력을 기다리면 말풍선, 끝나면 점프와 말풍선이 뜬다. 훅 스크립트는 `tools/digimon/agent-hook.sh`, 설치 방법은 `agent-hooks.md`에 있다. 설정 파일 수정은 안전장치가 막아서, 합친 파일을 만들어 두고 사용자가 직접 적용하게 했다.

- **첫 졸업 확인**: 빠른 성장으로 알에서 졸업까지 한 바퀴를 돌려 보니, 새 알이 2분 만에 부화해 줄기를 고를 틈이 없었다.
- **알 기다림**: 새 알은 줄기를 고를 때까지 부화하지 않는다. 24시간이 지나면 자동으로 정한다. 졸업 배웅 연출도 넣었다.

- **진화 선택 없앰**: 기기 기준 진화는 그대로 두고, 후보가 여러 개여도 키운 방식으로 가장 잘 맞는 쪽으로 바로 진화한다(사용자 결정). 고르기 모드는 스위치로 남겼다.

### 2026-11-12: 성향, 기분, 새 줄기

- **성향**: 홈에 "지금은 ○○ 쪽으로 자라고 있어요"와 백신·데이터·바이러스 막대, 이번 단계 기록이 나온다.
- **기분**: 한도가 100%면 아파하고, 새벽엔 졸려한다. 잡은 버그 수가 나오고, 가끔 큰 버그(3번 맞혀야 잡힘, 3마리로 셈)가 나온다.
- **새 줄기**: 피요몬, 텐타몬, 브이몬, 길몬을 넣었다. 6줄기, 106종이다. 합체 전용 진화는 규칙으로 잠갔다. 74종 기술 이름은 에이전트 2개가 공식 한국어 도감에서 조사했다.
- **메뉴바**: 컬러판이 없는 종은 큰 도트를 부드럽게 줄인다.
- **참고**: 병렬 테스트에서 `SnapshotHistoryRenderingTests`가 한 번 멈췄다. 다시 돌리면 통과한다.
- 자세한 내용은 `step5-tendency-moods-lines.md`에 있다.

### 2026-11-20: 포켓몬 코드 지우기

- **사용자 요청:** 원본(PokeTokenBar)에서만 쓰이고 디지토큰바에서는 안 쓰는 코드와 그 테스트를 지운다. 문제가 생기지 않도록 엄격하게 분석한 뒤 지운다. 원래는 공개 배포 때 지우기로 했던 일을 앞당겼다. 원본의 업데이트를 받아오기는 이제 어렵다.
- **순서:**
  1. 같이 쓰던 타입을 포켓몬 파일 밖으로 옮겼다. 앱 언어, 한도 창, 스프라이트 비율 맞추기, 가져오기 확인 단추가 그것이다.
  2. 앱 언어를 포켓몬 세이브(`companion-state.json`) 밖의 앱 설정(`appLanguage`)으로 옮겼다. 처음 켤 때 예전 세이브에서 언어 한 칸만 읽어 오고, 그 파일은 건드리지 않는다.
  3. 포켓몬 파일을 지우고, 섞여 있던 파일(앱 시작, 설정, 팝오버, 기간 요약, 메뉴)을 정리했다.
  4. 테스트와 문서를 정리했다.
- **지운 것:** 앱 코드 파일 21개(약 11,200줄), 테스트 파일 12개(약 4,400줄).
  - 포켓몬 화면·저장·PokéAPI·플로팅 펫·가방·상점·난이도 등이다.
  - 원작자 메일로 가던 "문제 알리기", 포켓몬 문구에만 쓰이던 한국어 조사 도우미, 안 쓰는 문구 225개도 지웠다.
  - 포켓몬만 쓰던 값 몇 개도 지웠다: 소모 속도 등급, 최고 한도 사용률, 한도 경고 상태, 등 돌리기 메뉴, 정사각 맞춤 함수.
- **엄격하게 확인한 방법:**
  - 지울 파일의 모든 선언을 남은 코드에서 찾았다. 공용인 것은 먼저 옮겼다.
  - 파일을 지운 뒤 컴파일 오류로 남은 사용처를 모두 드러냈다.
  - 남은 코드 전체에서 아무도 안 쓰는 선언을 찾았다. 지우기 전 코드에도 같은 검사를 돌려, 이번에 새로 안 쓰이게 된 것만 지웠다(전부터 테스트용으로 남아 있던 것은 그대로 둠).
  - 문구는 이름이 흔하면 다른 것과 겹친다. 예: 졸업 문구 `graduated`가 디지몬 사건 이름과 같아 쓰이는 것처럼 보였다. 그래서 문구 묶음을 통해 부르는 경우만 세는 검사로 다시 확인했다(10개 더 찾음).
- **찾은 결함:**
  - 기간 요약 화면이 아직 포켓몬 저장소를 읽었다. 도감 이름이 빈 항목이 있으면 PokéAPI에 이름을 물었다. 포켓몬 도감이 비어 있으면 실제 요청은 나가지 않는다. 이제 디지몬 졸업 기록과 디지몬 그림을 보여 준다.
  - 화면 문구에 포켓몬이 남아 있었다. 기간 요약의 "졸업한 포켓몬이 없어요", 오른쪽 클릭 메뉴의 "Pokédex"(영어 등), 설정 설명의 "포켓몬 성장", 추적 계정 설명의 "컴패니언 기분"(이미 없는 기능), 독일어 펫 문구.

- **보이는 곳:** 도감 디지멘탈 칸에 황금 2종을 따로 금색으로, 30점이 되면 "30점으로 받기". 홈의 아머 진화 단추는 금색, 콩고몬은 디지멘탈마다 단추. 황금 아머 진화는 금빛 반짝임이 조금 더해진다. 알림 "황금 디지멘탈을 받았어요!", "황금 아머 진화!".
- **예전 황금 조각:** 저장에 그대로 남고 보이지만, 디지멘탈로는 바뀌지 않는다.
- **숫자:** 진화 1,735 → 1,741개, 디지멘탈 경로 19 → 26개, 쓰는 디지멘탈 8 → 11종. 생성기 멈춤 조건 4 → 10가지, 모두 멈추는 것을 확인했다.
- 새 테스트 16개, 전체 1,366개 통과. 황금을 조각에 넣기, 단계 건너뛰기 없애기, 29점에 바꿔 주기, 금빛 반짝임 끄기를 각각 해 보면 테스트가 실패한다. 자세한 내용은 `step16-golden-digimentals.md`.

### 2026-11-23: 개인 기록 정리와 공개 전환

- **왜:** 공개를 앞두고, 문서에 소유자의 실제 사용량 숫자, 실제로 키운 기록, 말 그대로의 인용, 이 Mac의 경로가 남아 있었다.
- **정리:** 지금 문서 15개에서 53곳을 지우거나 가정한 예로 바꿨다. 원본에서 갈라진 뒤의 커밋 103개도 다시 써서, 모든 커밋의 문서를 정리된 최종본으로, 조사 파일의 경로를 저장소 기준 경로로 바꿨다. 다시 쓴 커밋 전부에서 지운 조각을 찾아 0건인 것을 확인했다.
- **새 저장소:** 덮어 올리면 깃허브가 예전 커밋을 한동안 남기므로, 새 저장소 `DigiTokenBar`에 정리된 기록만 올리고 예전 저장소는 지웠다.
- **다시 들어오지 않게:** `RepositoryPrivacyTests`(문서·코드에 이 Mac 경로가 들어가면 실패), CLAUDE.md "개인 기록 금지" 줄, `defect-log.md` 항목.
- **공개 전 확인:** MIT 라이선스와 원본 저작권 표기, README의 출처·비공식 팬 프로젝트 안내, 디지몬 그림은 저장소에 없음(앱이 Wikimon에서 받음), 저장된 비밀값 없음.
- **공개로 바꿨다.** 이제 깃허브 자동 검사가 무료로 돈다.

### 2026-11-23: 첫 배포판 v0.1.0, Homebrew, 홈 창

- **배포:** v0.1.0 을 GitHub Release(zip)로 냈다. 공증은 받지 않는다(무료). `release.sh` 는 원본 저장소·cask·서명 대신 우리 것을 가리키게 고쳤고, `pipefail` 아래 `grep -q` 가 맞는 서명을 실패로 판정한 버그를 고쳤다(`defect-log.md`).
- **Homebrew:** 공개 탭 `deadlylaid/homebrew-tap`. `brew install --cask deadlylaid/tap/digitokenbar && open -a DigiTokenBar`. cask 가 격리 표시를 지워 첫 실행 경고가 없다. 배포 8단계가 cask 의 버전·sha256 을 맞춘다. 앱의 업데이트 버튼은 brew 로 깐 경우 brew 로 올린다.
- **홈 창(사용자 지적):** 다른 Mac 에 brew 로 깔고 켰는데 아무것도 안 보였다. 앱은 돌고 있었고, 메뉴 막대가 꽉 차 아이콘이 노치 뒤에 숨어 있었다(macOS 는 숨은 아이콘을 꺼낼 방법이 없다). 이제 처음 켜면 팝오버와 같은 홈이 일반 창으로 뜨고(맨 위에 메뉴 막대 안내 한 줄), 앱을 다시 열면(Spotlight, 응용 프로그램 폴더, `open -a`) 언제든 그 창이 뜬다. 두 번째 실행부터는 저절로 뜨지 않는다. 실제 앱으로 세 경우를 확인했다.

### 2026-11-25: 하루 경험치 상한 없애기와 성장 속도 (17단계, 이슈 #4)

- **사용자 결정:** 하루 상한(150)을 없애고, 필요 경험치를 10배(알에서 졸업까지 10,200)로 올리고, 성장 속도를 설정에서
  0.5 / 1 / 1.5 / 2 / 5배 중에 고르게 한다. 빠른 성장(테스트, 10분의 1)은 그대로 두고 속도 위에 곱한다.
- **왜:** 하루 수억 토큰을 쓰는 사용자는 하루 대부분이 상한 뒤라 버려졌다. 상한만 없애면 하루 만에 졸업하니 필요 경험치를
  함께 올렸고, 사람마다 사용량이 수십 배 달라 속도를 고르게 했다.
- **예전 저장:** 저장에 경험치 단위(`expScale`)를 새로 적고, 읽을 때 예전 저장이면 지금 단계 경험치와 오늘 경험치를
  10배로 바꾼다(막대 그대로). 켤 때·가져올 때·백업 되돌릴 때 모두 같은 관문을 지난다.
- **화면:** "오늘 얻은 경험치 1,230", 설정의 "성장 속도" 고르기. 자세한 숫자는 `step17-growth-speed.md`.
- **덤:** 독일어 홈 렌더링 테스트가 저녁에 병렬로 돌리면 가끔 실패했다. 실제 시각을 쓰는 새 저장이라, 손님이 온 뒤에는
  손님 줄이 기간 비용 줄을 화면 밖으로 밀었다. 그 테스트의 디지몬 시계를 자정 직후로 고정했다.
